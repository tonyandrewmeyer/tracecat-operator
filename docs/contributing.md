# Contributing

See [`CONTRIBUTING.md`](https://github.com/tonyandrewmeyer/tracecat-operator/blob/main/CONTRIBUTING.md)
in the repository root for the full development guide, including:

- `uv`-based dependency management
- Running unit tests (`uv run pytest tests/unit`)
- Running integration tests (`uv run pytest tests/integration`)
- Pre-commit setup (ruff, mypy, yamllint, actionlint)
- Conventional Commits and PR conventions
- The Apache-2.0 (charm) vs AGPL-3.0 (workload) licence distinction
